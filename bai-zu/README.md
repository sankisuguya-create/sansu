# 何倍でしょう 図（3年「何倍でしょう」）

テープ図と関係図を、モニターに段階的に映す教師提示用ページ。1ファイル・外部通信なし。

## 使い方
- 上の欄で問題を選ぶ（教科書 p.13〜19 の問題を内蔵）。「問題をつくる」で数と名前を変えた問題も作れる（このブラウザに残る）。
- 「つぎへ」（→・スペース・PageDown＝プレゼン用リモコン）で1段ずつ出す。下の段階ボタンで直接とべる。
- 「テープ図」「関係図」で片方だけにできる。「全画面」（F キー）でモニター用。

## 段階
| 量が2つ（第1〜3用法） | 量が3つ（a の b 倍の c 倍） |
|---|---|
| 問題 → もとにする量 → くらべる量 → **区切る** → 式 → 答え | 問題 → 1つめ → 2つめ → 3つめ → **順に** → **まとめて** → 答え |

- **区切る**：くらべる量のテープを、もとにする量の長さで1つずつ区切り、番号を数える。指導書「つまずきと対策」の「倍」と「違い」（12−2＝10）の取り違えへの手立て。
- **まとめて**：関係図に 1つめ→3つめ の「6倍（3×2）」の矢印を出し、テープを1つめの長さで区切り直す。

## 設計メモ
- 色：教科書の紙面ふう（背景 #FAF8F3）。塗りは淡青・淡黄・白の3段まで（color-coding スキルの上限）。全色を check-palette.mjs で検査済み（本文16.4:1・青6.2:1・補助7.7:1、塗りの上の文字も5.9:1以上、2色覚でも見分け可）。量の区別は名前と行の位置で運び、色は補助。投影で淡色が飛んでも枠線で読める。
- □の答えは「答え」の段まで出さない。量が3つの時の2つめは「順に」で出す。
- テープの長さは答えの値で描く（教科書の図と同じ。□の段階でも長さの比は見える）。
