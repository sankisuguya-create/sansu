# 何倍でしょう 図（3年「何倍でしょう」）

テープ図と関係図を、モニターに段階的に映す教師提示用ページ。1ファイル・外部通信なし。

## 使い方
- 上の欄で問題を選ぶ（教科書 p.13〜19 の問題を内蔵）。「問題をつくる」で数と名前を変えた問題も作れる（このブラウザに残る）。
- 「つぎへ」（→・スペース・PageDown＝プレゼン用リモコン）で1段ずつ出す。下の段階ボタンで直接とべる。
- 右上で「両方／テープ図だけ／関係図だけ」。「全画面」（F キー）でモニター用：上下の操作部分が消え、→・PageDown・画面の右2/3タップで次へ、←・左1/3タップで前へ、Esc で戻る。

## 段階
| 量が2つ（第1〜3用法） | 量が3つ（a の b 倍の c 倍） |
|---|---|
| 問題 → もと → 目盛り → くらべる → 下線 → 囲む → 枠 → 〇倍 → 左 → 右 → 数 → 式 → 答え | 問題 → 1つめ → 目盛り → 2つめ → 3つめ → 下線 → 囲む → 枠 → 〇倍 → 左 → 中 → 右 → 数 → 順に → まとめて → 答え |

- **テープ図**：0の縦線と、下の目盛りの線（0(倍)・1・2・…を目盛りの上に書く）。くらべる量のテープは、もとにする量の長さで区切って出す（テープの中に番号は書かない）。
- **下線・囲む**：問題文の「の〇倍」に赤い矢印の下線、関係図の左の四角に入るもの（もとにする量）を赤い四角で囲む。関係図を作る準備。問題データの text で `{ }`＝矢印の下線、`[ ]`＝四角。
- **関係図**：枠（空の四角と矢印）→ 矢印の「〇倍」→ 左の四角の中 →（中）→ 右の四角の中 → 四角の下の数。
- **まとめて**：関係図に 1つめ→3つめ の「6倍（3×2）」の矢印を出し、3つめのテープを1つめの長さで点線で区切る。

## 設計メモ
- 色：教科書の紙面ふう（背景 #FAF8F3）。塗りは淡青・淡黄・白の3段まで（color-coding スキルの上限）。全色を check-palette.mjs で検査済み（本文16.4:1・青6.2:1・補助7.7:1、塗りの上の文字も5.9:1以上、2色覚でも見分け可）。量の区別は名前と行の位置で運び、色は補助。投影で淡色が飛んでも枠線で読める。
- □の答えは「答え」の段まで出さない。量が3つの時の2つめは「順に」で出す。
- テープの長さは答えの値で描く（教科書の図と同じ。□の段階でも長さの比は見える）。
