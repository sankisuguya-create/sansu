# 円の模様エディタ — GAS版（先生の棚・児童の提出つき）

先生どうしで図を共有でき、児童は課題に図を提出できる版。図は設置した先生のスプレッドシート「円の模様エディタ 先生の棚」に保存される（初回の保存で自動作成）。

## 設置（1回だけ）
1. https://script.google.com で新しいプロジェクトを作る（名前：円の模様エディタ）。
2. `Code.gs` の中身を `コード.gs` に貼る。
3. ファイル「+」→ HTML → 名前を `index` にして、`gas/index.html` の中身を全部貼る（`../index.html` ではない）。
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**児童（@kyoiku.edu.nishi.or.jp）も開ける範囲**。
     「edu.nishi.or.jp 内の全員」で児童が開けなければ「Google アカウントを持つ全員」にする（管理者の設定次第。未確認）。
5. 初回は承認画面が出る（スプレッドシートの作成・編集の許可）。発行された URL（…/exec）を先生に配る。

## 使い方
- 「先生用」を開くと「先生の 棚に 保存」「棚から 開く」が出る。
- 保存した人だけがその図を上書き・削除できる。ほかの先生の図は開いて（新しいタブ）、自分の名前で保存し直せる。
- 児童のアカウント（@kyoiku.edu.nishi.or.jp）では棚を使えない。

## 児童の提出
1. 先生用 →「児童の 提出を 見る」（または `…/exec?page=teacher`）で、課題を作る。
2. 「児童用の URLを コピー」で `…/exec?kadai=課題名` を Classroom に貼る。
3. 児童は右上の「提出する」を押す。何回でも出し直せ、一覧には各児童の最新が出る（「前の 提出も 見る」で全部）。
4. カードを押すと、その図がエディタの新しいタブで開く。
- 提出はスプレッドシートの「提出」シートに、縮小画像つきで残る。課題の一覧は「課題」シート。
- **児童のメールが取れない場合**（実行ユーザー＝自分で、児童のドメインが別扱いの時に空になる。未確認）は、提出時に名前を入れてもらい、その名前で一覧に出る。

## 直した時（../index.html を変えた時）
```
python3 gas/build.py      # circle-pattern フォルダで。gas/index.html を作り直す
```
- `Code.gs` と `gas/index.html` は**同じコミットから両方**貼り直す（版がずれると画面に警告が出る）。
- デプロイの「管理」→ 鉛筆 → バージョン「新バージョン」で更新する（URL は変わらない）。

## なぜ本体を Base64 で埋め込むか
GAS は配る HTML の JS コメントを消す。文字列内の `//`（例：SVG の名前空間 URL）が巻き込まれる恐れがあるため、本体を Base64 にして入れ、ブラウザで戻して実行する。長さが合わなければ画面に「ページが こわれています」と出る。
