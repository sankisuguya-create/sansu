# sansu

算数の授業用Webアプリ集。

| アプリ | 単元 | 内容 |
|---|---|---|
| [sphere-cut](sphere-cut/) | 3年「円と球」 | 球（高さ3cm・1m・300m）をいろいろな位置・かたむきで切り、切り口の円を比べる教師提示用アプリ。切り口の記録とスライドつき |
| [circle-pattern](circle-pattern/) | 3年「円と球」 | ます目に円をかき、交点で区切られた線を消し、囲まれた所を塗って模様を作る児童・教師用エディタ。ます目の数・1ますの分け方（2つ／5つ）・こさを変えられ、全画面表示もできる。A4横で印刷。1ファイル・ブラウザ内保存 |
| [circle-pattern/problems.html](circle-pattern/problems.html) | 3年「円と球」 | コンパスで模様をかく問題プリント8問（A4横・1マス＝1cm）。手がかりは段階的に減らす。教師用解答・エディタ用データつき |
| [bai-zu](bai-zu/) | 3年「何倍でしょう」 | テープ図と関係図を段階的に映す教師提示用ページ。教科書 p.13〜19 の問題を内蔵、自作問題も可。「区切る」「まとめて」の動きつき。1ファイル |

GitHub Pages で公開する場合: Settings → Pages → Branch: main / root。
